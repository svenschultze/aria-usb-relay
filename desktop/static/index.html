GET CONNECTED

A few steps. Then you’re live.

Use the same local network for your phone and computer. Connect the glasses to the phone by USB.

01

Connect your phone

Enable Developer options → Wireless debugging on Android 11 or newer.

Available devices

Find paired devices, or connect using the address below.

Use the address on the main Wireless debugging screen. It can change after reconnecting to Wi-Fi.

Pair a new phone

On the phone, choose “Pair device with pairing code” and keep that dialog open.

Pairing and connection ports are different. The code is never saved.

02

Prepare the relay

Install the Android app, then connect your Gen 1 glasses to the phone with a USB data cable.

  1. Enable the glasses’ ADB access in Aria Companion.
  2. Install and open Aria USB Relay on the phone.
  3. Tap Start relay and allow USB access and the session notification.
  4. Keep Wireless debugging enabled. You can leave the phone app and turn off its screen.

Uses the APK in dist/aria-usb-relay.apk or your local debug build. Android may request USB permission again when the glasses change modes.

One glasses device per relay

Select the intended phone explicitly. Other phones and firmware versions should be validated before a research session.

03

Prepare this computer

The official Aria Client SDK runs on Linux. Windows uses WSL2 with mirrored networking.

Run setup checks to inspect the SDK, USB drivers, phone connection, and local environment.

Connection settings

Settings are saved locally and excluded from Git. Pairing certificates stay with the official SDK.

First-time SDK installation

Open a terminal in the repository. The setup helper installs Linux dependencies and the official SDK only when you run it. Pair the SDK with your glasses using Aria Companion before streaming.

Get connected again

Phone is unavailable

Check its Wi-Fi and Wireless debugging address. Reconnect from Setup; pair again only if Android has forgotten this computer.

Waiting for USB access

Open the phone app and approve Android’s USB prompt. Unplug and reconnect the glasses if the USB interface remains unresponsive.

Cameras have paused

Stop the stream, confirm the phone relay is ready, then start again. Stale frames are marked in the live view.

Linux asks for permission

Launch the dashboard with scripts/open-dashboard.sh in a terminal. It requests sudo for the USB transport; the dashboard and SDK run as your normal user.

Before sharing a report

Export omits images, sensor samples, pairing codes, and certificates, and masks known device identifiers. Review the file before posting it publicly.
